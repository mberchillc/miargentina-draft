# MIArgentina

Sitio estático de MIArgentina construido en HTML, CSS y JavaScript, a partir del mockup aprobado por el cliente.

## Desarrollo local

No requiere compilación ni dependencias. Servir esta carpeta con cualquier servidor HTTP local y abrir `index.html`.

## Cloudflare Pages

- Framework preset: `None`
- Build command: vacío
- Build output directory: `/`

Los archivos `_headers` y `404.html` están preparados para Cloudflare Pages.
